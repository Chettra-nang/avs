┌──────────────────────────────────────────────────────────────────────────────┐
│ 🚀 MANUAL TRAINING STEPS                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

  1. Export Dataset (10 sec)
     ─────────────────────────
     python AVs/scripts/export_offline_dataset.py \
         --input data/ambulance_dataset_diagnose \
         --output data/offline_dataset

  2. Verify Pipeline (1 min)
     ────────────────────────
     python AVs/scripts/verify_offline_pipeline.py

  3a. Train Offline DQN (15 min)
      ──────────────────────────
      cd rl/Ambulance_EGO_4500\ 2/Ambulance_EGO_4500/tools
      python train_offline_dqn.py \
          --dataset ../../../../AVs/data/offline_dataset/offline_dataset.npz \
          --output ../checkpoints/offline_dqn \
          --epochs 100 \
          --device cuda

  3b. Train Behavior Cloning (5 min)
      ───────────────────────────────
      python train_bc.py \
          --dataset ../../../../AVs/data/offline_dataset/offline_dataset.npz \
          --output ../checkpoints/bc_pretrain \
          --epochs 50 \
          --device cuda

│ ⚠️  DATASET ISSUES FIXED                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

  Your collected parquet data had problems:
  
  ❌ Duplicate rows (3x same step)      → ✅ Deduplicates by agent_id=0
  ❌ No next_obs                        → ✅ Reconstructs from step+1
  ❌ Action format [0,0,0,0]            → ✅ Converts to discrete (argmax)
  ❌ Mixed shapes (4D singletons)       → ✅ Canonicalizes to (C,H,W)
  
  All fixed by export_offline_dataset.py automatically!
